# CyberGuard – Digital Arrest & Impersonation Scam Defence

## About the Project

CyberGuard is an AI-powered cybersecurity platform designed to detect and prevent digital arrest scams and impersonation fraud.

It helps users identify suspicious calls, fraudulent messages, fake authority claims, and online scams.

## Key Features

- AI-based scam detection
- Digital arrest scam identification
- Suspicious message analysis
- Impersonation fraud detection
- Risk alerts and safety guidance
- Cybercrime awareness and reporting information

## Technology Stack

## Installation

1. Clone the repository:

```bash
git clone https://github.com/anujilla/CyberGuard-Digital-Arrest-Defense-frontend.git
```

2. Open the frontend folder:

```bash
cd CyberGuard-Digital-Arrest-Defense-frontend/frontend
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Build for production:

```bash
npm run build
```
